# Intigriti LeakyJar Challenge

**Challenge:** LeakyJar Challenge  
**Vulnerability Category:** Cross-Site Request Forgery (CSRF)  
**Severity:** Medium (Tier 2)  
**Status:** Archived / Resolved  

## Challenge Premise
The LeakyJar application contains a private recipe vault. The objective is to steal the admin Master Baker's secret recipe (the flag). Users can report a recipe URL to the Master Baker (admin bot), who will visit the provided URL.
